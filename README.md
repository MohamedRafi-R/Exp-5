# AIM:
To draw UML Diagrams for the Student Enrollment System
# SRS (Procedure):
◉ Use Case Diagram

◉ Class Diagram
◉ Activity Diagram
◉ Package Diagram
◉ Communication Diagram
◉ Sequence Diagram
